# PKOK Main

https://www.pkok11.com/ ওয়েবসাইটটার একদম পিক্সেল পারফেক্ট UI ক্লোন করো। শুধু ফ্রন্টএন্ড (UI/UX), কোনো গেম, লগইন ফাংশন, ব্যাকএন্ড বা পেমেন্ট লাগবে না।

পুরোপুরি Responsive হতে হবে, বিশেষ করে মোবাইলের জন্য। Dark + Neon theme ঠিক আসল সাইটের মতো রাখো (Gold, Purple, Red, Cyan accent)।

প্রতিটি সেকশন মিস না করে একদম একইভাবে বানাও:

টপ নেভিগেশন বার

লোগো (PKOK / PKOK11)

মেনু আইটেমস (হোম, গেমস, প্রমোশন, VIP ইত্যাদি)

ল্যাঙ্গুয়েজ সিলেক্টর, Login & Register বাটন

হিরো সেকশন

বড় ব্যাকগ্রাউন্ড ইমেজ

বড় হেডলাইন বাংলায়

সাবহেডলাইন

বড় বড় CTA বাটন ("এখনই জয়েন করুন", "অ্যাপ ডাউনলোড করুন" ইত্যাদি)

গেমস সেকশন

গেম কার্ডের গ্রিড (স্লট, রুলেট, ক্র্যাশ, ফিশিং গেম ইত্যাদি)

থাম্বনেইল + গেম নাম + Play বাটন (শুধু দেখানোর জন্য, গেম চালু করার দরকার নেই)

প্রমোশন / বোনাস সেকশন

ওয়েলকাম বোনাস, ডেইলি রিওয়ার্ড, সুপার রিওয়ার্ডস ইভেন্ট ইত্যাদি ব্যানার

কেন PKOK সেকশন (ফিচারস)

আইকন + টেক্সট (নিরাপদ, দ্রুত উত্তোলন, ২৪/৭ সাপোর্ট, জ্যাকপট ইত্যাদি)

অ্যাপ ডাউনলোড সেকশন

Android APK ডাউনলোড বাটন + QR কোড এরিয়া

টেস্টিমোনিয়াল / ইউজার রিভিউ

ফুটার

সব লিংক, সোশ্যাল আইকন, কপিরাইট

অতিরিক্ত নির্দেশনা:

আসল সাইটের কালার, ফন্ট, স্পেসিং, বাটন স্টাইল, হোভার ইফেক্ট, অ্যানিমেশন সব একদম মিলিয়ে দাও।

বাংলা টেক্সট যেভাবে আছে সেভাবে রাখো।

মোবাইল ভিউ একদম সুন্দর করো।

Tailwind CSS ব্যবহার করো।

একদম ১০০% ভিজ্যুয়াল ক্লোন বানাও যাতে কোনো সেকশন মিস না হয়।
